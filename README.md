Sri Anjaneya Swamy Temple — Thappagondanahalli

Official community & heritage web portal for the sacred Sri Anjaneya Swamy Temple situated in Thappagondanahalli village, Challakere Taluk, Chitradurga District, Karnataka. Managed and preserved traditionally by the local Gowdru families and village elders.

📍 **Google Maps**: [View Location & Directions](https://maps.app.goo.gl/etwqM3uwJgdi93HK8)

---

## ✨ Features

- **🌐 Full Bilingual Support**: Instant seamless toggle between **English** and **ಕನ್ನಡ (Kannada)** across all pages.
- **📜 Verified Historical Chronicles**: Archival documentation of the sanctum, Nayaka-era stone architecture, Veeragallu pillars, and oral traditions.
- **🗓️ Daily Timings & Pooja Schedule**: Detailed morning & evening Darshan timings, Mahamangalarathi, and special Tuesday/Saturday archana schedules.
- **🎉 Annual Festivals & Calendar**: Hanuman Jayanti, Rathotsava, and village fairs with downloadable `.ics` calendar events.
- **📸 Community Photo Archive & Submissions**: Public photograph gallery and devotee submissions with verification review.
- **🗺️ Directions & Travel Logistics**: Detailed road route from Bangalore, Chitradurga, Challakere, and Bellary with integrated Google Maps navigation.
- **📱 Responsive & Accessible**: Optimized for mobile phones, tablets, and desktops with high-contrast sacred aesthetics.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide Icons & Custom Sacred Emblems
- **Hosting**: Google Cloud / AI Studio Run Platform
